# سكريبت إرسال إشعارات FCM — الدهشان

بيراقب الأوردرات، وأول ما أوردر يتسند لطيار بيبعتله إشعار فوري (Push) يوقظ
تطبيقه ويشغّل الرنين — حتى لو التطبيق مقفول تمامًا.

> **مجاني بالكامل.** إرسال FCM مجاني، وتشغيل السكريبت على جهازك مجاني.
> مش محتاج خطة Firebase المدفوعة (Blaze).

---

## خطوة 1 — نزّل مفتاح الخدمة (مرة واحدة)

1. افتح: <https://console.firebase.google.com/project/aldahshaneg-92f66/settings/serviceaccounts/adminsdk>
2. تأكد إنك مختار مشروع **aldahshaneg**.
3. اضغط **Generate new private key** (توليد مفتاح خاص جديد) → **Generate**.
4. هينزل ملف JSON. غيّر اسمه لـ **`serviceAccountKey.json`** وحطه **جوه فولدر
   `fcm-sender` ده بالظبط** (جنب `index.js`).

> ⚠️ الملف ده **سرّي جدًا** — بيدي تحكم كامل في المشروع. متبعتهوش لحد ومترفعوش
> على جيت هب (مضاف في `.gitignore` بالفعل).

---

## خطوة 2 — ثبّت المتطلبات (مرة واحدة)

محتاج **Node.js** متثبّت على الجهاز (<https://nodejs.org> — نسخة LTS).
بعدها من داخل الفولدر ده:

```bash
npm install
```

---

## خطوة 3 — شغّل السكريبت

```bash
npm start
```

هيطبع "🚀 السكريبت شغّال وبيراقب الأوردرات..." — **سيبه مفتوح**. أول ما أوردر
يتسند لطيار، هيبعتله الإشعار ويطبع سطر تأكيد.

---

## فين أشغّله؟

- **الأبسط:** على **كمبيوتر المكتب/الفرع** اللي بتتسند منه الأوردرات — هو أصلاً
  شغّال وقت الشغل (ووقت الشغل هو وقت الأوردرات). لو الكمبيوتر اتقفل، الإشعارات
  بتوقف لحد ما تفتحه وتشغّل السكريبت تاني.
- **يشتغل 24 ساعة (اختياري):** على سيرفر مجاني للأبد زي **Oracle Cloud Free
  Tier**، أو Raspberry Pi صغير. قوللي لو عايز أظبطهولك.

### تشغيل دائم على ويندوز (يفضل شغّال ويبدأ مع الجهاز)
أسهل طريقة: استخدم **pm2**:

```bash
npm install -g pm2
pm2 start index.js --name dahshan-fcm
pm2 save
```

لو عايزه يبدأ تلقائيًا مع تشغيل الويندوز، قوللي أظبطلك ده.

---

## إزاي بيشتغل (باختصار)

1. تطبيق الطيار بيسجّل "توكن" الجهاز في `pilotFcmTokens/{pilotId}`.
2. السكريبت ده بيسمع نود `orders`. لما أوردر يبقى `status = "جاري التوصيل"`
   وعنده `pilotId`، بياخد توكن الطيار ويبعت إشعار FCM (data + أولوية عالية).
3. الإشعار بيوصل عن طريق Google Play (اللي الجهاز مبيقتلهاش) → بيوقظ التطبيق
   ويشغّل الخدمة الخلفية → الرنين يبدأ ويفضل لحد ما الطيار يفتح التطبيق.
4. `fcmState/{orderId}` بيمنع تكرار الإشعار لنفس الأوردر/الطيار.
